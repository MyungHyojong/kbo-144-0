# KBO 144–0 · Next.js Edition

Next.js App Router 기반의 배포용 KBO 드림팀 게임입니다. UI와 서버 API를 하나의 Next.js 프로젝트에서 관리합니다.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다. Vercel에 GitHub 저장소를 연결하면 별도 서버 설정 없이 배포할 수 있습니다.

`lib/players.ts`는 MVP 예시 데이터입니다. 실제 배포 전에 사용 권한이 있는 정확한 KBO 기록으로 교체하세요.
